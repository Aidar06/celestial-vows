# Celestial Vows

Самостоятельный двуязычный шаблон свадебного приглашения. Данные загружаются по числовому ID из URL (`/3`, `/4`) через Xano API, при ошибке используется `dist/content.json`. RSVP отправляется полным объединённым объектом и обновляет список гостей без перезагрузки.

```powershell
node scripts/serve.mjs
node scripts/check.mjs
```

Локально доступны `/`, `/3`, `/4` и другие числовые маршруты. Для Vercel настроен SPA fallback в `vercel.json`; папка публикации — `dist`.
